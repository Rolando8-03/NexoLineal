# Banco de demostración

Los **19 proyectos JSON versión 1** se aceptaron con el codec de producción y se resolvieron con el núcleo Python. No contienen resultados ni comprobaciones importados: la aplicación los vuelve a calcular.

Descargá un proyecto y abrilo desde **Historial y proyectos → Importar archivo**, o copiá su JSON en **Ver o pegar JSON**. En el proyecto podés editar los datos, cambiar modo/tema, seleccionar pasos, ampliar la gráfica y exportar PDF/CSV cuando exista tabla.

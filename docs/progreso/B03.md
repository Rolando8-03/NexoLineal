# B03

Se incorporaron index.html, css/estilos.css, los tres JavaScript, los iconos y los lanzadores originales. Las comprobaciones locales encontraron las rutas de recursos referenciadas y aprobaron la sintaxis JavaScript.

El recorrido gráfico se ejecuta en Chromium desde GitHub Actions. Carga el Python real, introduce un sistema 2x2 con solución [2,1] mediante las celdas de la interfaz, pulsa Resolver sistema y comprueba el resultado. Luego navega a Calculadora y calcula (8+2)/5. El artefacto guarda JSON y capturas.

Los primeros intentos con el navegador del entorno local no completaron la conexión al servidor. Por eso el cierre utiliza la ejecución remota y su resultado verificable, según docs/fase01/cierre.md cuando esté disponible.
